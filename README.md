# decryptor
Text Decryptor
Консольное Java-приложение для дешифровки текстов, зашифрованных шифром Цезаря (Rot-N) или простым шифром подстановки - с помощью частотного криптоанализа.

# Как это работает
Программа принимает зашифрованный текстовый файл и пытается восстановить исходный текст одним из двух способов:
Шифр Цезаря (Rot-N) - буквы алфавита сдвигаются на известное число позиций `N`. Дешифровка выполняется обратным сдвигом.
Частотный анализ - для алфавитов без известного сдвига. В тексте подсчитывается частота каждого символа, после чего самые частые буквы текста сопоставляются с самыми частыми буквами языка (для английского и русского алфавитов используется статистически типичный порядок букв).
Поддерживаются русский и английский алфавиты. Символы, не входящие в алфавит (пунктуация, цифры, пробелы), не изменяются; регистр букв сохраняется.

# Запуск
Проект рассчитан на компиляцию и запуск через IntelliJ IDEA (JDK 21, без систем сборки).
```
java decrypt.MainDecryptor <входной_файл> <выходной_файл> <алфавит> <дешифратор>
```
Параметры:
Параметр	Значения	Пример
`алфавит`	`EN`, `RU`	`EN`
`дешифратор`	`FREQ`, `ROT<N>` (любое целое)	`ROT3`, `ROT-1`, `FREQ`
Пример:
```
java decrypt.MainDecryptor input.txt output.txt EN ROT3
java decrypt.MainDecryptor input.txt output.txt RU FREQ
```
Список найденных замен (`старая_буква -> новая_буква`) выводится в стандартный поток вывода, расшифрованный текст сохраняется в выходной файл.


# Тестирование
